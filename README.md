# Programa-Git

Repositorio de práctica para el control de versiones con Git y GitHub, realizado como parte del
programa Análisis y Desarrollo de Software del SENA.

## Contenido

| Archivo | Descripción |
|---|---|
| `README.md` | Descripción del repositorio |
| `.gitignore` | Archivos que Git debe ignorar |
| `docs/comandos-git.md` | Resumen de los comandos básicos de Git local y remoto |

## Flujo de trabajo

1. Crear el repositorio local con `git init`.
2. Guardar cambios con `git add` y `git commit`.
3. Vincular el repositorio remoto con `git remote add`.
4. Enviar los cambios con `git push`.
